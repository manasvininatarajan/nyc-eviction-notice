# nyc-eviction-notice

A plain-language crisis resource for NYC tenants who 
have received an eviction notice.

Built for caseworkers to share with clients facing 
housing emergencies. Includes:

- Step-by-step guidance written in plain language
- Real phone numbers for free legal aid by borough
- Emergency rental assistance programs
- Know-your-rights FAQ
- Interactive document checklist

https://yourusername.github.io/nyc-eviction-guide/

## Why I built this
I built this as part of preparing for the Claude Corps

affects thousands of New Yorkers every year.
